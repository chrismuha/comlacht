# Original source archive

These files contain only code removed from the active files during the redesign. They are intentionally not imported by the live application, so the recovered styles and components cannot affect the deployed website.

`App.original.vue`, `HomeView.original.vue`, and `main.original.css` are complete because their former contents were replaced in full. `main.deleted.js` contains only the two router lines removed from `src/main.js`.

The working application remains in `src/App.vue`, `src/Views/HomeView.vue`, `src/main.js`, and `src/assets/main.css`.
